# 缠论形态识别与研判

## 用途

基于**缠中说禅**理论的价格结构分析，完全依赖价格形态。核心链路：原始K线 → 去包含处理 → 分型识别 → 笔检测 → 中枢构建 → 买卖点判定。适用于任何有 OHLCV 数据的市场（A股、港股、美股）。

在 Decidra 中，本技能经内置的 **czsc_lite** 引擎（自 czsc 0.9.69 移植的纯 Python 实现，与原版逐值比对基准）与 czsc/strategy 两组 MCP 工具执行，无需外部 czsc 库。

## 核心概念

| 概念 | 说明 | 详细文档 |
| --- | --- | --- |
| 分型（FX） | 顶分型：中间K线最高；底分型：中间K线最低 | [分型](references/核心概念/分型.md) |
| 笔（BI） | 相邻顶底分型之间的一段走势，缠论最小单元 | [笔](references/核心概念/笔.md) |
| 中枢（ZS） | 至少3笔构成的价格重叠区域，趋势的核心 | [中枢](references/核心概念/中枢.md) |

## 买卖点体系

| 买卖点 | 含义 | 详细文档 |
| --- | --- | --- |
| 一买/一卖 | 趋势结束后的第一个反转信号（背驰点） | [一买一卖](references/买卖点/一买一卖.md) |
| 二买/二卖 | 一买/一卖后回调不破底/顶的确认信号 | [二买二卖](references/买卖点/二买二卖.md) |
| 三买/三卖 | 中枢上移/下移后回调不进入前中枢的信号 | [三买三卖](references/买卖点/三买三卖.md) |

## 在 Decidra 中如何执行

优先调用 czsc MCP 工具做结构与买卖点分析，不要自行实现缠论算法。

| 工具 | 用途 | 关键参数 |
| --- | --- | --- |
| czsc_chan_analysis | 单级别缠论分析：分型/笔/中枢结构 + 已触发的精选买卖点信号 | symbol（yfinance 码）、period（默认 1y）、freq（日线/周线/月线/60分钟/30分钟/15分钟）、params（di 回溯第几笔、ma_type/timeperiod 均线设定等） |
| czsc_multi_level_analysis | 多级别联立：日/周/月逐级结构 + 相邻级别中枢共振，回答“日线买点与周线趋势是否共振” | symbol、period（默认 5y）、freqs（默认 日线/周线/月线）、params |
| czsc_list_signals | 列出全部可用缠论信号函数名与说明摘要 | 无 |

标的代码用 yfinance 格式：港股 0700.HK，A股 600519.SS / 000001.SZ，美股 AAPL。

## 研判落盘（结合策略告警）

Decidra 的 cron 策略会把缠论共振告警写入 alerts。对某条告警做人工或 AI 研判时：

| 工具 | 用途 |
| --- | --- |
| strategy_alerts_list | 列出最近策略告警（含是否已研判的状态） |
| strategy_alert_enrich | 对指定告警写回研判结论（支持/反对/观望 + 置信度 高/中/低） |

标准研判流程：strategy_alerts_list 定位目标告警 → czsc_multi_level_analysis 多级别复核该标的 → strategy_alert_enrich 落盘结论。监控终端可直接输入 /enrich 触发这一流程。

## 信号方向约定

- 做多：一买 / 三笔向上盘背 / 五笔类一买 / 三买（中枢上移后回调不破前中枢）
- 做空：一卖 / 三笔向下盘背 / 五笔类一卖 / 三卖（对称）
- 中枢辅助：价格在中枢下沿附近做多占优，上沿附近做空占优

## 说明

多级别分析中各级别数据同源（日线本地重采样出周/月线，避免跨源复权差异）。多级别工具会附带 K 线质量问题（data_quality_issues）与相邻级别中枢共振结果（cross_level_signals）。
